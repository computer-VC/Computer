How a transport chatbot answers you

Big Data collects past user inquiries and expected answers about route planning. Cloud Computing provides the computational resources to process that data, train the model, and apply it to new queries. Machine Learning (often a neural network) maps an input query to an appropriate output response.

Example: a rider asks “How do I go to Central?” — the trained model replies with a route.
