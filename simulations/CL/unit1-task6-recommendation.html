Part B · Learning recap

Brief definitions that support Tasks 5 and 6:

Big Data

Massive amounts of data and information that can be used for AI model training and testing.

Machine Learning

Algorithms that produce models for input processing and output generation, enabling the AI system to learn and improve automatically from data. A trained model can then perform tasks on new data it has never seen before.

Cloud Computing

Computational resources to support AI technologies — fast, scalable processing for training and prediction.
